# Mohammad Sarhangzadeh — Personal academic website

This website is a static HTML/CSS/JS project intended for `https://msarhangzadeh.github.io/`.

## Preview locally

Double-click `index.html` to open the site in your web browser. No build process or backend is needed.

## Files

- `index.html`: website content
- `assets/css/styles.css`: styles and responsive layout
- `assets/js/main.js`: navigation / footer enhancement
- `assets/images/`: profile photo and `mmd` favicon
- `assets/figures/`: four research-paper figures
- `assets/cv/Mohammad_Sarhangzadeh_CV.pdf`: updated two-page CV linking to this website
- `assets/cv/Mohammad_Sarhangzadeh_CV.tex`: editable XeLaTeX source for that PDF

## Publish to GitHub Pages

Create the **public** repository `MSarhangzadeh/msarhangzadeh.github.io` and add the website files at its root. In GitHub's repository **Settings → Pages**, select **Deploy from a branch → main → /(root)**, then Save. It can take some time to become publicly reachable.

The site itself is unchanged from the approved v4 design, other than metadata identifying the intended GitHub Pages URL. The CV in `assets/cv/` has been regenerated to replace the former NeuraVision Lab website header link with `msarhangzadeh.github.io`.
